Arquitectura de Base de Datos

Modelo Entidad-Relación dividido por Módulos - Ecosystem ADSO

Módulo 1: Usuarios y Jerarquía Académica

Gestión de roles, programas, fichas y sistema de notificaciones/auditoría.

            erDiagram
                USUARIOS {
                    int id PK
                    string nombre
                    string correo
                    string rol
                    int id_programa FK
                    int id_ficha FK
                }
                PROGRAMAS {
                    int id PK
                    string nombre_programa
                }
                FICHAS {
                    int id PK
                    string codigo_ficha
                    int id_programa FK
                }
                APRENDICES {
                    int id PK
                    int id_usuario FK
                    int id_ficha FK
                }
                INSTRUCTORES {
                    int id PK
                    int id_usuario FK
                    string especialidad
                }
                NOTIFICACIONES {
                    int id PK
                    int id_usuario_destino FK
                    string mensaje
                }
                LOGS_AUDITORIA {
                    int id PK
                    string accion
                }

                PROGRAMAS ||--o{ FICHAS : "tiene"
                PROGRAMAS ||--o{ USUARIOS : "pertenece_a"
                FICHAS ||--o{ USUARIOS : "pertenece_a"
                FICHAS ||--o{ APRENDICES : "tiene"
                USUARIOS ||--o| APRENDICES : "es"
                USUARIOS ||--o| INSTRUCTORES : "es"
                USUARIOS ||--o{ NOTIFICACIONES : "recibe"
